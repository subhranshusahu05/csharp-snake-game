# 🐍 C# Console Snake Game

A console-based Snake Game built using C#.

## 🚀 Features
- Real-time snake movement
- Collision detection (walls & self)
- Dynamic snake growth
- Score tracking
- Game Over & Restart system

## 🛠 Technologies Used
- C#
- .NET Console Application

## 🎮 How It Works
The game uses a continuous game loop that:
1. Moves the snake
2. Checks for collisions
3. Updates the snake's position history
4. Renders the grid in the console
